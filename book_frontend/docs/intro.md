# Introduction to ROS 2 for Humanoid Robotics

Welcome to the educational module on ROS 2 Fundamentals for Humanoid Robotics. This course is designed for Computer Science students with Python and basic AI knowledge who want to learn how to use ROS 2 as middleware connecting AI agents to humanoid robot control systems.

## What You'll Learn

In this module, you will:

- Understand the fundamental concepts of ROS 2 middleware
- Learn how to implement communication patterns using nodes, topics, services, and actions
- Explore how Python AI agents use rclpy to control robots
- Create and understand URDF models for humanoid robots
- Connect AI agents to humanoid robot control systems

## Prerequisites

- Basic Python programming knowledge
- Fundamental understanding of AI concepts
- Interest in robotics

## Getting Started

Begin with Module 1: The Robotic Nervous System (ROS 2) to learn the foundational concepts that will guide your understanding of how AI agents interact with humanoid robots through ROS 2.
